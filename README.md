# Cafetería React

Aplicación frontend para registrar, listar y editar ventas de una cafetería escolar.

## Requisitos

- Node.js 18+
- npm

## Instalación

```bash
npm install
```

## Ejecutar en desarrollo

```bash
npm run dev
```

## Compilar para producción

```bash
npm run build
```

La aplicación consume la API REST que expone el backend en `http://localhost:3000` para estudiantes, productos y ventas.
